# Event Management System 
Event Management System with role-based access control. Teachers create event requests, HOD approves/rejects them, students view and register department-wise events, and the principal can view all events and download reports. Built using React, Node.js, and MongoDB.

# Run Project
1. Frontend Run :

Event-Management-Sys\frontend --> npm run dev

2. Backend Run :

Event-Management-Sys\backend --> nodemon server.js
